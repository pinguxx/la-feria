Hecho para Rendimiento y Conexión en Vivo

Cada uno de los juegos que componen La Feria está desarrollado con un backend nativo en Rust con Tokio y Axum, ofreciendo latencias ultrabajas mediante WebSockets, cero dependencias pesadas de audio (Web Audio API procedural sintetizada) y despliegues listos en Docker y Render.

⚡ Rust Tokio + Axum
Manejo asíncrono concurrente de salas multijugador con consumo mínimo de RAM.
🔌 WebSockets Nativos
Canales bidireccionales en tiempo real para votaciones, turnos y lanzamientos.
🔊 Audio Procedural
Efectos de sonido y melodías de organillo sintetizadas 100% en código de cliente.
🛡️ CI/CD Quality Gates
Pipelines automatizados con Clippy, rustfmt, tests unitarios y escaneo Trivy.
// Servidor WebSocket de La Feria (Axum + Tokio)
use axum::{routing::get, Router};
use tokio::sync::broadcast;

async fn iniciar_feria() {
  let (tx, _rx) = broadcast::channel(128);
  let app = Router::new()
    .route("/ws", get(feria_ws_handler))
    .with_state(tx);
  // ¡Servidor listo a 60fps con latencia < 5ms!
  axum::serve(listener, app).await.unwrap();
}
